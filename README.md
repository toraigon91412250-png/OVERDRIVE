# OVERDRIVE — Kinetic Protocol

外部通信・ログイン・課金を必要としない、単体HTMLの3D FPSローグライトです。

## 進撃 / 市街地奪還

本編の進撃モードは、通常6・顎3・鎧2・超大型1の合計12体を同時配置する討伐ゲームです。ワイヤーで街を飛び、雷槍や刃で戦い、Tキーで自分が進撃の巨人に変身して戦えます。全12体を倒すとクリア。単体訓練も選べます。

PC操作: 右クリック長押しで左右ワイヤー、離すと解除。巨人を狙うと吸着して肩・背後へ接近し、近距離のクリックで斬撃へ踏み込みます。WASD移動、SHIFTガス、SPACE離陸/空中噴射。Rで雷槍を装備→次のRで発射（2発ごと自動装填）、Fで刃に戻す。クリック/Fで斬撃、Bで刃交換、Vで視点切替、Gで設定。

Tで巨人化。巨人化中はWASD移動、SHIFT走行、SPACE跳躍、クリック/Fで拳、Tで人間に戻ります。ゲージ切れ/巨人体の耐久切れでも離脱。巨人を倒すと人間の耐久・ガス・雷槍・巨人化ゲージを補充します。超大型のとどめは立体機動でうなじへ。

`npm run build`で公開用`dist/index.html`、進撃単体`dist/ODM_TITAN_RAID.html`、単体の本編`dist/OVERDRIVE.html`を生成。公開メニューは進撃のHTMLを必要時だけ読み込み、ダウンロード用HTMLにはモデルを内蔵しています。検証は`npm run test:titan`。[詳細](docs/TITAN_CITY_RAID_REBUILD_2026-11-15.md)。

## Σ / FRACTURE RAID（v8.1・新難易度）

前回のΩを残したまま、新難易度Σを追加しました。Σは近接型・突進型中心で、射撃型は最大1体、浮遊射撃型は出現しません。再構築時のボス弾幕も3発に抑えています。F／専用ボタンで0.55秒だけ敵弾を捕獲し、最大6発をまとめて返撃。ダッシュで弾へ踏み込む捕獲にも対応します。6発返撃は衝撃波と防壁破壊を起こし、射線と通路を自分で開けます。青く光る継ぎ目の防壁は全武器でも破壊可能。左手の専用立体アーム、6セル表示、亀裂・破片を追加しました。

ΩとΣはタイトルから別々に選択でき、記録も別々です。`npm run test:fracture` で編成、弾数、捕獲、実射、壁破壊、Ωとの分離を検証できます。詳しい仕様と検証限界は [Σ開発レポート](docs/FRACTURE_RAID_V8.md) を参照。

## Ω / RIFT RAID（v7.0）

Ωを20秒の任務攻略FPSへ作り直しました。封鎖装置3基を撃ち壊す、中継点2か所を1.25秒ずつ制圧する、チェックポイント3個を順番に通る、指名標的2体を倒す、の4任務から抽選。5つのコアを奪うと次の世界で中枢ボスが現れ、撃破でクリア。任務を4回逃すか耐久が尽きると失敗です。

最初の武器だけ本編6武器から3択で選択。以後は20秒ごとに地形と武器が自動で入れ替わり、Q／専用ボタンで各世界1回だけ武器を引き直せます。時間の巻き戻しや無敵の付与はありません。任務中は敵が補充されるため全滅待ちは不要。レベルアップも自動強化になり、プレイは中断しません。成功後はE／次へボタンですぐ進むか、残り時間で回復や経験値を拾うかを選べます。

破壊炉・制圧端末・通過ゲート・標的マーカーは専用の立体モデルで表示。目的地の画面マーカーと距離表示、任務HUDを追加しました。既存の8種の地形構造×5種の戦場規模と、地形に連動する敵編成を継承しています。

検証は `npm run test:omega`、`npm run test:world`、`npm run test:weapon-parity`。詳細と実行環境の限界は [RIFT RAID開発レポート](docs/RIFT_RAID_V7.md) に記録しています。

## 起動

PCでは `dist/OVERDRIVE.html` をWebGL 2対応ブラウザで開き、「出撃する」を押してください。初回クリックで音声を開始し、PCではマウスポインターをロックします。ESCで停止します。

iPhone Safariでは横向き表示を推奨します。公開中のゲームは https://overdrive-kinetic.pzjm42rjpc.chatgpt.site から開けます。「ファイル」アプリのQuick LookではJavaScriptゲームが実行されない場合があります。スマホ操作は左スティックで移動、右側をドラッグして照準、FIRE長押しで射撃します。縦画面にも対応しますが、横画面の方が遊びやすい配置です。

ローカル配信例（Python 3があるPC）：

```sh
python3 -m http.server 8080 --directory dist
```

PCは `http://localhost:8080/OVERDRIVE.html`、同じLAN上のiPhoneは `http://PCのLANアドレス:8080/OVERDRIVE.html` をSafariで開きます。ネットワークのファイアウォール設定に依存します。公開サービスへの登録は不要です。

## ウェーブ専用ギミック（v5.9）

各ウェーブに立体モデル付きの専用ギミックを追加しました。Wave 1はジャンプ台、Wave 2は進行方向へ飛び出す4基の加速盤、Wave 3は空中でジャンプを長押しする短時間の低重力浮遊、Wave 4は乗って高さを取れる油圧リフト、Wave 5は撃つと敵を露出させるリレー、Wave 6はWARDENのコア露出を延長するリングアンカーです。加速盤は約0.82秒、浮遊は最大1.8秒。リレーは敵への与ダメージを3.4秒間35%上げ、ボス戦アンカーはコア露出を4.6秒に延長します。かんたんと現在の難易度で同じギミックを使用します。

ギミック模型は稼働中のウェーブだけ表示します。繰り返し部品はインスタンス化し、加速盤とリフトのメッシュ数を抑えています。武器・敵の基本能力値は変更していません。仕様・テスト・制限は [ウェーブギミックレポート](docs/STAGE_GIMMICKS_V5_9.md) を参照してください。

## 操作

タイトル画面で「パソコン／スマホ」と「現在の難易度／かんたん」を選べます。かんたんは敵の耐久と移動・射撃を抑え、自動照準補助、自動リロード、高耐久を備えます。パソコンは従来の操作です。

|操作|パソコン|スマホ|
|---|---|---|
|移動|WASD / 矢印キー|左スティック|
|照準|マウス|右ドラッグ / FIRE上でドラッグ|
|射撃|マウス左ボタン長押し|FIRE長押し|
|ジャンプ|SPACE|JUMP|
|ダッシュ|SHIFT|DASH|
|スライド|C|SLIDE|
|武器切替|1–6|GUN|
|狙撃照準|右ボタン長押し（ホイールで3×/6×）|右画面タップで3×→6×→解除|
|リロード|R|R|
|停止|ESC / PAUSE|PAUSE|

横画面推奨。感度・画質・音・タッチ照準補助をタイトルで変更できます。動作が重い場合はLOWを選んでください。非表示タブ・フォーカス喪失時は一時停止します。

## 遊び方

6ウェーブを突破し、最終ウェーブのWARDENと護衛を倒すとクリア。耐久0でゲームオーバーです。移動で熱量を蓄積し、通常8秒間のOVERDRIVEに入ります（慣性蓄電で延長）。満タン時にASTRA弾も12発補充。停止で熱量が減少します。ダッシュは短時間無敵です。かんたんでは敵の耐久が半分、敵の移動速度が約3分の2、攻撃頻度が下がります。受けるダメージを軽減し、照準補助・高耐久・短縮リロードが有効になります。初戦は敵1体から始まり、明るさと見通しも上げ、最初に移動・照準・射撃の案内を表示します。撃破時には簡単専用の連続撃破表示が出ます。

パルスは連射、散弾砲は近距離、レールは高威力と貫通。弾薬の総量は無限ですが、装填が必要です。敵の上部コアは高ダメージ。青い経験値オーブを拾い、レベルアップするたび、そしてウェーブクリア時にも4候補から能力を選びます。能力は各3段階まで重複します。未回収のオーブはウェーブ終了時に回収されます。ジャンプ台は緑色に発光する床です。レーダーの赤点が敵、黄色がボスです。

WARDENは扇状弾幕・援軍・地表衝撃波を使います。攻撃後にコアが露出する時間を狙ってください。地表衝撃波はジャンプまたはダッシュ無敵で避けられます。

スコア・周回数・クリア数はブラウザのlocalStorageに保存します。保存が禁止されていてもゲームは動きます。周回中の中断セーブ・永続能力解放・オンラインランキングはありません。

## かんたん専用・武器の練習（v5.4.1）

操作案内の後に、全6武器の役割とPC／スマホ操作を実際に試せます。無敵・予備弾無限。標的は繰り返し出現し、「スキップ / 次の武器へ」を押すまでその武器で自由練習できます。「全部スキップ」で本番へ直行できます。PCはEnterでも次へ、Tabでマウスを解放してボタン操作。

## ASTRA × VANTA / LIMIT RELEASE（v5.1）

PCは4キー、スマホはGUNで選択。出撃時12発、上限24発。移動ゲージ満タンで12発補充し、従来の8秒OVERDRIVEが発動。自動持ち替えなし。チュートリアルでは通常武器を使います。

- 短押し→離す：1発・45ダメージ。長押し→離す：0.12秒ごとに1発分を蓄積、残弾に応じ最大24発（2.88秒）。消費は発射時のみ。
- 2〜9発：貫通砲（最大4体、射程65m、遮蔽あり）。威力45×消費数。
- 10〜23発：NOVA（直撃1.6倍、距離減衰つき範囲攻撃と押し戻し）。
- **24発：EXPLOSION / NOVA IMPACT。照準地点を中心に半径16mの遮蔽対応ショックウェーブ。** 直撃は通常NOVA威力の1.35倍（24発時、基本2,333ダメージ）、衝撃波は最大0.75倍（中心で基本1,296、半径端で約259）から距離減衰。遮蔽物の裏・範囲外・未出現の増援は残り、通常のスコア・撃破・経験値処理を使います。ボスへの衝撃波は通常の対ボス係数適用後さらに0.2倍。生き残った通常敵を5〜9m押し戻し、0.84〜1.4秒ひるませます。
- EXPLOSION演出は約3.4秒。魔法陣、白熱球、炎の柱、多重衝撃波、残火、画面の爆光と「EXPLOSION」・実際の撃破数、専用の低音/風切りを組み合わせます。画面全体の演出は維持しますが、ダメージは狙った局所に限ります。演出中は被弾と移動・攻撃を止め、報酬と最終勝利は終わるまで待機。視点操作・一時停止は可能。画面の揺れ/爆光はOSの動き軽減設定で抑制。
- R／スマホの「チャージ」は残弾分の自動チャージを1回発射。24発ならEXPLOSION。満タン手前の任意の段階ではFIREを離して撃ちます。
- CAPACITOR/HOT STARTで補充を加速。AUTO FEEDは通常3銃のみ。ASTRAはOVERDRIVE中チャージ速度1.35倍。弱点・空中・スライド等は通常攻撃/NOVAに反映。最終奥義は確定撃破です。
- 一時停止・強化選択・武器切替・タッチキャンセルで未発射チャージを破棄。ホーム/再出撃で爆発・音・オーバーレイも解除。

ユーザー提供ASTRA_VANTA_HYBRID_v1の元ソースは `assets/astra-vanta/`。ゲーム用モデルは `src/phase-weapon.js`、最終奥義演出は `src/explosion-visuals.js` と `src/explosion-director.js`。外部画像・CDN・ポストプロセスは不要です。

## PHANTOM LANCE / 第5武器（v5.2）

ユーザー提供のPHANTOM LANCE試作モデルを基に、一人称用の軽量な手続きモデルとして統合しました。独立した試作ゲームは取り込まず、銃の外装・スコープ・発光コアを `src/phantom-lance.js` に移植し、静的パーツを素材ごとにまとめています。

- 1発装填、胴体120ダメージ、敵の上部コアは2.2倍（基本264）。距離減衰なし、弾は貫通しません。
- PCは右マウスを押して照準、ホイールで3×/6×。スマホは画面右側を短くタップして3×→6×→解除、ドラッグは通常どおり視点操作です。スコープ中は移動速度と照準感度を下げ、射撃の散らばりをなくします。
- 発射後、射撃ボタンをもう一度押すと自動で2.4秒の再装填を開始。Rキー／リロードボタンでも装填できます。弾の予備数は無制限で、武器切替中のリロードは解除されます。
- 射撃時は専用の発光フラッシュ、太いエネルギートレーサー、着弾粒子、反動を表示します。エネルギー兵器なので薬莢は出しません。AUTO FEEDの撃破補充対象からは除外しています。

## SEEKER / 第6武器（v5.3.1）

三連ランチャーから追尾ミサイルを発射。PCは6、スマホはGUNで選択。6発装填・1.9秒リロード。敵へ照準を約0.22秒合わせると最大3体をロックし、1体につき1発を振り分けます。照準を外しても0.7秒保持するので、複数の敵を順に捉えられます。

v5.3.1では画面下から構える位置・前を向く角度・センサー配置を調整。ミサイルは実際の銃口の向きへ発射してから追尾します。

誘導弾は基本84ダメージ、未ロック時の直進弾は32。射程42m、遮蔽物対応、対象撃破で追尾を終了。三連セルの発光・個別反動、マガジン装填、曲がる航跡、着弾リングを実装。詳細な数値と検証範囲は [docs/SEEKER_V5_3.md](docs/SEEKER_V5_3.md)。

## 再構築と検証

Node.js 20以上を推奨。依存関係の取得時のみネット接続が必要です。

```sh
npm ci
npm run build
npm run test:phase
npm run test:phantom-lance
npm run test:seeker
npm run test:training
npm run test:weapon-parity
npm run test:explosion
npm run test:enemy-visuals
npm run serve
# 別ターミナルで
npx playwright install chromium
npm test
node tests/production-smoke.cjs
```

`src/game.js` がゲーム、`src/style.css` がUI、`src/shell.html` がHTML、`build.mjs` が単体HTML生成処理です。3Dモデルはコードによる独自のプリミティブ構成。音はWeb Audio合成です。Three.jsのMITライセンスは `THIRD_PARTY_LICENSES.txt` に収録しています。

`?test=1` は自動テスト用で、ポインターロックを省略し、状態操作用の `overdrive.test` を公開します。通常URLには状態操作フックがありません。読み取り用 `overdrive.snapshot()` は通常版でも利用できます。テストは進行確認の一部で強制撃破や時間ステップを使います。人間が通常操作で全編クリアしたという意味ではありません。

## EVOLUTION / v2

通常敵はRIPPER（高速近接）、ARTILLERIST（三方向射撃）、WISP（浮遊・横移動）、RAM（予告線付き突進）。シルエットと動作を変更しました。武器には専用モデル・マズルフラッシュ・薬莢・可動部・射撃反動を追加。強化は14種類、各3段階です。レベルアップ選択中は戦闘停止、選択後は0.65秒の無敵時間があります。


かんたんモードの初回は、スキップ可能な操作チュートリアル（移動・射撃・経験値・ジャンプ台）が始まります。ジャンプ台は立体ブースターとして再設計し、全5か所に配置しました。通常難易度はチュートリアルなしです。

標準難易度では中央にアニメーションするリアクターを配置し、かんたんモードとは視覚演出を分けています。

武器の役割は両難易度で共通です。パルスは距離減衰と適正距離コア表示、散弾砲はノックバック、レールは長距離ボーナスとカードによる撃破時分裂を持ちます。かんたんでは各種の補助が有効です。

`npm run test:phase` はGPU描画を行わず、本体の戦闘・入力ハンドラ・進行処理を検査します。WebGLRendererとDOMを検査用の代替実装へ置き換えるため、実画面やタッチの押し心地を検証したものではありません。ブラウザ描画確認は `npm test` と実機テストで別途行います。
