# 巨人化後の格闘試作

今回の範囲は、踏み込みと右ストレートを中心に、巨人の身体で殴る感触を作ること。

- 提供された進撃の巨人GLBに腰・胸の回転軸を追加。元の指メッシュを曲げて拳を握り、逆の腕を構えたまま、腰、胸、肩、肘を順番に動かす。
- 0.16秒の振りかぶりから素早く伸ばし、地上では最大1.45m踏み込む。0.76秒で構えに戻る。右から開始し、次は左。戻りの最後0.22秒で次の入力を予約できる。
- 腕の左右ごとの実際のメッシュ位置から拳の目印を求める。攻撃区間中だけ前フレームからの軌跡を巨人の身体・頭部コライダーへ判定し、同じ攻撃で同じ敵に2回当てない。上半身から命中点への遮蔽も検査する。
- 命中時に0.085秒のヒットストップ、打撃音、拳専用の衝撃表示、カメラの短い振動を同期。敵はのけぞり、地形と外壁を確認しながら短く押し戻される。追跡用の経路探索は押し戻しには使わない。
- 巨人用の追従カメラは胸付近を注視し、少し肩側へ寄せて腕を見せる。歩行の脚振り、膝、足首、腰と肩の揺れは移動速度に合わせる。
- 変身シークエンスの4秒化は別の作業。この試作では巨人化後の格闘を先に確認する。

## 確認

`npm run build` と `npm run test:titan` 成功。新しい `tests/titan-punch.cjs` は振りかぶり中の無傷、腰・胸の回転、拳の接触、1回だけのダメージ、左右の交代、踏み込み、敵の押し戻し、ヒットストップ、横や背後への空振り、脚の動き、リセットを検証する。

実際のゲームループから取得したGLBのメッシュとポーズをBlenderで描画し、指・腕・胴体の姿勢も確認した。ブラウザでの実操作やWebGLの最終的な見え方はこの検証に含まない。

## ストレートの軌道と顔の修正

- 肩と肘の角度を直接補間する方法から、拳の目標位置へ2関節を合わせる処理に変更。両手を顔の横へ構え、攻撃中は同じ高さの前方へ伸ばす。腰・胸のひねりと踏み込みは維持する。
- 軌道テストで、打ち出し中の拳の高さの変化が0.35m以内、前方移動が2m以上、打ち切り時の上腕と前腕の方向一致が0.90超になることを確認。アッパーのように低い位置から上昇する回帰を検出する。
- 顔本体 `Mesh_150` は頂点カラーを持つが、GLBに専用材質と法線がない。頂点カラーを保ったまま滑らかな法線、両面描画、肌用材質、弱い間接光の補助を設定する。
- 顔の周辺の肌材質も調整。髪・目・口内の暗い材質は変更しない。修正は読み込んだ進撃の巨人モデルへ一度適用し、操作キャラと敵の両方で利用する。
- 材質・頂点カラーを含むポーズ画像をBlenderで描画して目視確認。ゲームのWebGL画面を直接検証したものではない。
