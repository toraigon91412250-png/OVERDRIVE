# v5.4.1 — 武器の基本仕様を共通化

かんたんで旧式の武器挙動を使っていた箇所を、現在の標準難易度の仕組みに揃えた。標準の設定値・倍率・発射間隔・装填数・強化候補の動作は維持する。

## 揃えた内容

|内容|かんたんの更新|
|---|---|
|装填数|パルス50、散弾10、レール6。ASTRA24・狙撃1・シーカー6は従来どおり。ASTRAの本番開始時は12発|
|パルス|同じ得意距離・立ち上がり・遠距離減衰・最大射程を使用。銃のコア色で距離を判断できる|
|散弾砲|同じ距離減衰、押し戻し、ひるみ、突進キャンセルを使用|
|レールガン|同じ遠距離ダメージ補正、貫通、カードによる撃破時分裂を使用|
|武器カード|中距離調整・衝撃装填・分裂導体をかんたんでも選べ、効果が働く|
|武器練習|中距離とコア色、近距離と押し戻し、遠距離と貫通を説明する内容へ更新。実際のかんたん本番と同じ共通ルールで試せる|

パルスの素の距離曲線は近距離2、得意距離7、遠距離で減衰して0という標準の式を維持。かんたんはその曲線に **16/7倍** の威力補助を掛ける。従来の得意距離での16ダメージを残しながら、近すぎ・遠すぎでは弱いという役割を共通化した。基準距離の基本ダメージは近距離約4.57、得意距離16、射程外0となる。

## 残したかんたんの補助

短縮リロード（標準の0.55倍）、PCの照準補助、スマホの照準補助、散弾のまとまりやすさ（spread 0.11、標準0.16）、電弧伝導の補助処理を維持。最低HP125、被ダメージ軽減、被弾後の無敵時間、移動・ダッシュ補助、敵のHP・速度・弾速・攻撃頻度の軽減、少なめの敵編成、明るさ・見通し・チュートリアルも変更していない。

ASTRA、PHANTOM LANCE、SEEKERの固有ルールはそのまま。練習中のみの無敵、予備弾無限、ASTRAの弾切れ補充、スキップまで待機、標的の再出現も維持する。

## 標準難易度を変えていないことの検証

実装前のゲームソース（コミット `2b2cea5c6b609ba7f2e031d8781330213fd9c341`）から、乱数シードを固定して標準難易度の比較結果を採録した。`tests/normal-weapons-v5.4.json` を参照し、更新後の `tests/normal-weapon-compatibility.cjs` で数値と候補を完全一致で比較する。

比較内容：距離別・強化段階別パルス曲線、各武器の実際の射撃ダメージ、散弾の押し戻し・ひるみ、装填数、射撃間隔、リロード、レールの分裂とカード併用、4種類のASTRA射撃、シード別の強化候補、敵HP・プレイヤー被ダメージ等。更新後も一致した。これは比較したシナリオの結果であり、全状況を網羅したという意味ではない。

`tests/easy-weapon-rules.cjs` では、かんたんの距離曲線＋補助倍率、コア色、散弾の減衰・押し戻しと衝撃装填、レールの遠距離補正・分裂、専用カードの選択、更新済み練習を検証。照準補助・短縮リロード・HP・被ダメージ・敵HP/移動速度・プレイヤー速度の維持も確認した。散弾の距離倍率比較は命中数と弱点倍率を固定し、かんたんの狭い散布による命中率の差と区別した。
