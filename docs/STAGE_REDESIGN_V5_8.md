# v5.8 / ウェーブ別アリーナ再編

ウェーブごとにステージの規模と輪郭を変え、武器や移動の選択理由が自然に変化するよう再構成しました。床タイルの間隔や基本の操作速度は維持し、広さはおもにタイル数で調整しています。武器の性能、敵の耐久・攻撃力、ウェーブの敵数は変更していません。

| Wave | 戦場 | 主な遊び方 |
|---|---|---|
|1|従来の64m級アリーナ|基本の見通しと移動を維持|
|2|約76×60mの回廊|壁で射線が分かれ、長い通路から進路を選び直す|
|3|約68m幅の浮遊島|橋と島を移動し、高低差をジャンプ台で越える|
|4|約68m幅の段丘|横方向に最大3.6mの高低差がつき、上段・遮蔽を使う|
|5|最大約84m幅の断層|斜めの長い射線と離れた足場で狙撃距離を作る|
|6|直径約76mの円形アリーナ|中央のボスと外周をつなぐ橋、柱を使った遮蔽戦|

Wave 2〜6は移動境界も各地形の大きさに合わせます。大きな地形では通常敵の出現距離を遠ざけ、Wave 5は他より長い距離から敵を見つけられる配置にしています。ミニマップは従来の表示倍率のまま画面内に地形を収めます。

背景は色の変更に加え、遠景の柱とゲートの高さ・幅・傾き・配置半径をステージ別に変えました。空、霧、地面、環境光、太陽光、リング、ジャンプ台が同じテーマへ移行します。戦闘中の足元付近に装飾物を増やさず、敵の視認性を保つ設計です。再構築演出は空白から始まり、各組み立て段階を約4秒に圧縮して再生します。広いステージは開始時の観覧カメラを少し遠くしました。

## 実装範囲と確認

- タイル上限を225から441に拡張。InstancedMeshで床・ワイヤー表示を再利用し、個別メッシュを大量に作る方式にはしていません。
- ステージ形状ごとにセル、遮蔽物、ジャンプ台、開始位置、敵の出現距離、移動境界を一緒に定義。
- 広いマップでプレイヤーと敵の移動が旧±30.8m境界に止まらないよう修正。
- EXPLOSIONの着弾中心が拡張マップの外で切り詰められないよう、現ステージ境界に連動。
- 武器、敵パラメータ、標準／かんたんの難易度設定は変更なし。

`npm run build` と `npm run test:world` が成功しました。自動テストでは両難易度の5回の再構築、報酬待ち・停止再開・免疫・再出撃に加え、5地形の連結性、開始地点とジャンプ台、壁の衝突・射線、落下復帰、段差、橋上の敵移動、ボス足場を確認しています。回廊の壁を広げた際に旧テストが期待する射線がずれましたが、壁の位置を戻して再実行し、すべて通過しました。

ブラウザでの目視・フレームレート計測、iPhone Safari実機での操作・発熱確認は未実施です。段差ルート、遮蔽を含む実戦時の敵経路、画面上での遠景の見え方は通しプレイで引き続き確認できます。
