# SEEKER — v5.3.1 実装メモ

ユーザー提供 `OVERDRIVE_SEEKER_weapon_v1.zip` の独立した視覚モデルを基に、ゲーム本体へ第6武器として統合。5番の PHANTOM LANCE を維持します。

## v5.3.1 一人称の構え修正

武器全体が画面内に浮く旧配置を、グリップ・後部が画面下へ続く構えへ変更。PCは位置(0.30, -0.39, -0.61)・縮尺0.70、スマホは(0.30, -0.37, -0.66)・縮尺0.66。内向きの角度は約25.8度からPC約1.15度／スマホ約1.03度へ抑えた。スマホの縦画面では横位置を画角に合わせる。

三連セルの高さを90%に抑え、上に載っていたセンサーは本体側面の支持レールへ移動。反動は銃口が上がって戻る向きに修正。

ミサイルは各ポートのワールド座標と方向を使用し、最初の0.075秒は発射口の軸へ直進、その後にロック対象へ旋回する。カメラ前方＋発射時の扇状オフセットを使う旧方式を解除。誘導・直進の威力、弾数、発射間隔、ロック範囲は従来どおり。

追加検証：PC／スマホ横／スマホ縦の投影で、武器が照準を空け、グリップが画面下へ続き、3ポートが画面内に見えることを確認。通常／反動中・回転した視点で、発射位置と初期方向がモデルのポートに一致し、最初の移動がその軸に沿うことを確認。未ロック弾の5m／15m／35m命中、従来の追尾・壁衝突・ボス係数等も通過。PHANTOM・ASTRA/NOVA・EXPLOSION（音声含む）・敵視認性の回帰テストとビルドも成功。

`sites-preview status` は引き続き `preview relay unavailable`。今回もブラウザ描画の目視とiPhone実機は未検証。数値投影で自然な見た目そのものを保証したわけではない。

## 操作と数値

- PC: `6` で選択、マウスで敵に照準、左クリックで発射、`R` で装填。
- スマホ: GUN で6番へ順送り。照準／FIRE長押し・ドラッグは共通。追加ボタンなし。
- 6発装填。発射間隔0.82秒、標準装填1.9秒。簡単の装填1.045秒。QUICK CHAMBER・OVERDRIVEの既存倍率に対応。
- 射程42m以内、照準からPC10度／スマホ13度の範囲に敵を約0.22秒捉えるとロック。視線が通る敵のみ。外れても0.7秒記憶し、照準を振って最大3体まで指定できる。
- 1射につきロック済みの異なる敵へ1発ずつ、最大3発。1体だけなら1発消費。残弾・飛翔プールの空き数まで発射。
- 誘導弾は基本84ダメージ、ロックなしの直進弾は基本32ダメージ。コア狙撃倍率・範囲ダメージなし。
- 空中／スライド／OVERDRIVE／追撃回路／電弧伝導は対応。共通damage()経由で撃破・経験値・誘爆等に連動。AUTO FEEDは説明どおり最初の3武器だけ。
- WARDENには通常の非露出0.55倍／露出1.8倍を適用。
- 速度28m/s、旋回上限4.8rad/s、寿命2.4秒、同時最大6発。対象撃破時はその場で消滅、対象の自動変更なし。ほかの敵にぶつかった場合はその敵へ命中。
- 壁・床に当たると停止。銃が壁に入り込んだ時は、発射位置を壁の手前に補正。武器切替後も飛翔し、一時停止／強化選択中は凍結。再出撃・タイトル・次ウェーブで解除。

## 見た目と負荷

三連発射口、面取り外装、ガイドセンサー、ガードを調整。ロック数でセル色が変わり、発射セルごとに反動、6つの窓で残弾を表示。側面マガジンの装填アニメーション付き。

実際の3Dミサイルがそれぞれの銃口から出る。短い排気炎、曲がる航跡、小さな放射状の着弾リングを表示。追尾マーカーは最大3つで入力を遮らない。

モデル42メッシュ・2,572三角形。ミサイルと着弾演出を固定プール化。航跡はInstancedMeshを使用、LOW／スマホで12区間から7区間へ短縮。追加ライト・外部画像・ポストプロセス・外部依存なし。

## この更新で実施した検証

`npm run test:seeker` は本体を実Three.js＋非描画DOM/rendererで実行。PC／タッチの切替、ロック時間・射程・遮蔽・失効、複数目標への発射、実弾の追尾・敵死亡・壁停止、直進／誘導ダメージ、ボス係数、残弾・リロード・カード、プール上限、一時停止・持替え・再出撃、簡単／チュートリアル、モデル頂点正常性・画面投影を確認。

`test:phantom-lance`、`test:phase`、`test:explosion`（音声を含む）、`test:enemy-visuals`、ビルドも通過。既存Playwrightテストの弾数一覧を6武器に更新したが、この更新ではブラウザE2Eを実行していない。

このセッションはSitesのブラウザ操作モジュールがなく、`sites-preview status` も `preview relay unavailable`。ブラウザ描画・視覚的な仕上がり・iPhone Safari実機・FPS・人間の通しプレイは未検証。数値投影は描画の代替検証ではない。

## v5.3初版の検証で修正した点

発射時の扇状の広がりを強めたところ、近距離で横へ動く敵を通り過ぎるケースを新規テストで発見。目標までの距離に応じて広がりを縮小し、近距離の追尾と遠距離の見映えを両立した。静的モデル結合では混在していた頂点インデックスを揃えて初期化エラーを修正した。最終修正後に関連テスト一式とビルドを再実行して通過。
