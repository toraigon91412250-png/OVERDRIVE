# Ω / RIFT RAID — 現行ルール（v7.0）

Ωは30秒ごとに世界・銃・任務が変わる、任務攻略型のFPSです。

- BREACH：光る封鎖装置3基を射撃で破壊。1基46HP。全武器で攻撃可能。
- RELAY：光る中継点2か所を順に制圧。各地点の近くで1.25秒キープ。
- ROUTE：光るチェックポイント3個を順番に通過。
- HUNT：マーカー付きの敵2体を撃破。通常の敵だけを倒しても任務進捗は増えません。

任務成功でコア1個、1000点、耐久12回復、4秒のOVERDRIVE。成功後はE／次へボタンですぐに次の世界へ進むか、30秒まで残って回復・経験値を回収するかを選べます。3コアで次の世界にWARDENが現れ、撃破でクリア。任務を6回失敗、または耐久0でゲームオーバー。ボス戦では任務失敗を数えず、30秒ごとにボスHPを引き継いで世界を再構築します。

開始時だけ本編6武器から3択。以後の世界では本編6武器＋Ω生成武器から自動交換します。現装備を連続では選ばず、未使用武器を優先。Q／専用ボタンで各世界1回だけ引き直せます。引き直しでは時間・HP・無敵時間をリセットしません。

戦闘は敵全滅待ちで進みません。通常は最大6体、ボス戦はボス込み最大4体まで補充。レベルアップは最大耐久+3、耐久5回復、装填速度を自動改善し、選択画面で停止しません。

再構築は1.55秒。敵弾と攻撃エフェクトを消去し、全武器を装填、生き残った通常敵のHPを維持して再配置します。最初の中枢ボス出現時には通常敵を整理し、以後ボスを複製しません。PCでは再構築中もマウスロックを保持します。

地形は従来の8種のルート構造×5規模を継承。目標位置は歩行可能な経路長を調べて配置し、通常の1区間を24m以内に抑えます。生成武器は125戦闘ビルド・3125外観レシピを持ち、生成武器に交換されるごとにランシードと世界番号から再生成されます。

ソース：`src/omega-raid.js`（進行）、`src/omega-raid-visuals.js`（3D目標）、`src/game.js`（戦闘統合）。検証結果は `docs/RIFT_RAID_V7.md` を参照。
