# OVERDRIVE 5.6 — 世界の再構築

ウェーブ報酬と保留中のレベルアップを全て選択した後、4秒の構築を開始する。従来の構築段階を順番に保ち、映像全体を短く再生する。冒頭は旧アリーナ・空・リング・足場・背景を消し、リングの出現、床のワイヤーフレーム、下から飛来する実体タイル、上空から降りる防壁、ジャンプ台、背景構造物と空の順に構築。最後は観覧カメラが新しい開始地点へ降りる。

## 地形

| Wave | 戦場 | 主な変化 |
|---|---|---|
|1|起動|既存アリーナ。操作と武器の基本を学ぶ開放空間|
|2|蒼の回廊|195床タイルと長い防壁4基。曲がり角で射線が切れ、迂回が必要|
|3|空中庭園|77床タイル。空中島と細い橋、148区画の空白。ジャンプ台で橋を越える|
|4|段丘要塞|169床タイル。0〜3.6mの段丘と防壁。横移動で登り、高所や壁の裏を使う|
|5|断層交差路|153床タイル。傾斜した外周と斜めの交差橋、最大5.4mの高低差|
|6|終端の王冠|157床タイル。中央の高台、4本の橋と環状通路、外周の遮蔽柱でボスと戦う|

全地形の歩行可能区画から開始地点へ接続がある。ジャンプは近道に使えるが、橋をたどる地上ルートも存在する。地形に武器の固定制限は設けていない。遮蔽・高低差・落下箇所によって射線と移動経路が変わる。

## 戦闘との連動

- 新しい床と壁は実際の射撃・移動・着地判定に参加する。旧地形の当たり判定は2ウェーブ目以降無効化。
- 敵は床の接続と段差を調べて経路を選択する。配置時も壁の内部や空白を避ける。
- 落下は安全地点へ復帰し、通常の被ダメージ補正を通した14ダメージを受ける。復帰後は短時間無敵。
- 高いジャンプ台でも発射判定が働く。Wave3は初速22、Wave5は24、Wave6は21。それ以外は19.6。
- 高所で経験値を落とした場合も床の上に出現。空中強化は高台に立つだけでは発動しない。
- ミニマップには足場・空白・壁・ジャンプ台も表示する。
- 再構築中は戦闘・敵出現・経過時間が止まり、ポーズ・再開・タイトル戻り・再スタートに対応。

## 再利用と処理負荷

5.5のリング、中央炉、16本の支柱、6組のゲート、スキャンリング、色パレットを再利用。既存アリーナはWave1とチュートリアルに残し、既存ジャンプ台モデルを新しい地形へ配置する。床225枚・壁16基を上限としてInstancedMeshを使い回す。足場端に光る縁取りを置き、落下箇所を見分けやすくする。

## 検証

`npm run test:world` は全5地形の歩行接続・開始位置・ジャンプ台、移動と弾を遮る壁、空白と実体の射線、落下復帰、高いジャンプ台、橋上での敵の経路選択、高台着地、ボス配置、カード待ち、空白からの開始、ポーズ・再開、初期化、両難易度での全ウェーブ遷移を確認。

既存のASTRA、SEEKER、スナイパー、EXPLOSIONと音声、チュートリアル統合テストも通過。ビルドと差分チェック通過。

ブラウザ描画の目視・実iPhoneでのフレームレートや発熱は未確認。利用できるブラウザ操作環境が無いため、ロジック検証を描画検証の代用とは扱っていない。
