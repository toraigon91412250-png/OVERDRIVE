# OVERDRIVE v5.4.4 — かんたん専用・武器の練習

## 流れ

かんたんの既存の操作案内・模擬戦闘が終わると、6武器の練習へ入る。操作案内の「武器の練習へ」から直接始めることもできる。「チュートリアルをすべてスキップ」は従来どおり本番へ直行する。

武器ごとに役割・PCまたはスマホの操作・試す内容を表示。最初は大きく、2秒後に小さな参照カードへ収まる。標的を倒したり待機しても自動で次へ進まない。主ボタン「スキップ / 次の武器へ」で1つ進み、6番では「スキップ / 本番へ」。「全部スキップ」は途中でも本番へ移る。

PCはEnterでも次の武器へ進む。Tabでマウスポインターを解放してボタンを操作できる。練習へ入った直後もポインターを解放する。ESC／PAUSEでは通常どおり一時停止。練習中の武器は固定し、数字キーやGUNで説明と違う銃に切り替わらないようにした。

PCの基本チュートリアルでは、Wで前、Aで左、Sで後ろ、Dで右の順に、4つの光る目印まで実際に歩いて進む。案内には次の方向とルートの進み具合を表示し、移動中は視点を前に固定する。4地点を順に通った場合だけ次へ進み、スキップも可能。スマホのスティック案内はこれまでどおり。かんたん中はHUDと練習カードの武器名を「連射ライフル」「近距離ショットガン」「貫通ライフル」「チャージ砲」「スナイパーライフル」「追尾ミサイル」と簡略表示する。標準難易度の表示と武器仕様は変更しない。

## 各武器

|順|武器|内容と標的|
|---|---|---|
|1|パルスライフル|中距離、緑のコア色、近遠の距離減衰、連射と装填。正面の標的1体|
|2|散弾砲|近距離でまとめて当て、敵を押し戻す。近い標的2体|
|3|レールガン|遠距離補正と、一直線の標的3体への貫通を試す|
|4|ASTRA × VANTA|短押し光弾・長押しNOVA・24発EXPLOSION。本番の移動ゲージによる補充も説明|
|5|PHANTOM LANCE|遠い標的のコア、3×／6×照準、1発ごとの装填|
|6|SEEKER|ゆっくり横移動する3体のロック・追尾・振り分け|

v5.4.1からは標準と共通の距離特性・コア色・ノックバック等を、かんたんの補助を付けた状態で練習する。詳しい共通化と維持した補助は [WEAPON_PARITY_V5_4_1.md](WEAPON_PARITY_V5_4_1.md)。

## 練習ルール

- 無敵。標的は攻撃せず、全部倒すと約0.85秒で再出現する。
- 予備弾は無限、装填数・リロード・発射間隔はかんたんの実際の武器を使用。HUDにも装填中の実弾数を表示し、弾切れと装填を試せる。
- ASTRAは24発で開始し、弾切れで24発を自動補充。最大チャージを何度でも試せる。EXPLOSIONを撃っても練習は終了しない。
- 練習の撃破は専用カウンターへ表示。スコア・本番の撃破数・XP・強化カード・記録には加算しない。
- 本番へ進むと体力、弾薬、熱量、位置、装備、XP、スコア、経過時間を出撃直後の状態へ戻す。通常の初期特性は維持。ASTRAは本番用の12発に戻る。
- 武器の切替・全スキップ・タイトル・再出撃では、練習の標的、未発射チャージ、追尾弾、爆発演出・音を整理する。

標準難易度には武器練習を挿入しない。標準の武器・敵・マップ・進行の設定値は変更していない。新しいUIのスタイルは練習中のクラスに限定する。

## 検証

`npm run test:training` は実際のゲーム本体をThree.jsの数学・3Dモデルと非描画DOM／rendererで動かす。PC／タッチ双方で以下を確認：

- 通常の操作案内からの導線、武器練習への直接移動、標準難易度での侵入防止。
- 6段階の固定武器、手動進行、撃破・待機で進まないこと、標的再出現、無敵。
- 撃破・XP・スコア・報酬の混入防止、実弾数とリロード、狙撃照準、貫通、誘導。
- PCマウス／タッチFIREの入力による各武器の射撃、R／チャージボタンによる最大チャージ。
- EXPLOSION後も継続・補充・再出現。チャージ中／爆発中のスキップ、押しっぱなし入力の持越し防止。
- Enterリピートでの飛ばし過ぎ防止、Tab、一時停止／再開、途中の全終了、ホーム・再出撃。
- 本番開始時の初期弾数・HP・熱量・XP・タイマー等の初期化、標準の通常敵HPと被ダメージ。

`test:seeker`、`test:phantom-lance`、`test:phase`、`test:explosion`（音声含む）、`test:enemy-visuals`、ビルド、`git diff --check` も通過。既存Playwrightの操作案内完了後の期待値を武器練習への移行に更新し、テストファイルの構文を確認した。

この環境はSitesのブラウザ操作モジュールがなく、`sites-preview status` も `preview relay unavailable`。この更新のブラウザE2E、レイアウトの目視、iPhone Safari実機、実際の文字の読みやすさ／タッチ操作感は未検証。非描画テストはそれらの代替ではない。
