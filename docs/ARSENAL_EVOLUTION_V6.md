# 武器進化 — v6.0

パルス以外の5武器に、合計20枚の専用カードと10本の進化ルートを追加した。各武器は「コア増幅 → 2ルートから1つ選択 → 最終進化」の3回の選択で完成する。ルートは周回中に固定され、反対ルートへの切替や完成済みカードの重複取得はできない。既存のパルス進化も利用できる。両難易度・PC・タッチ操作に対応する。

未強化時の武器設定、敵の基本能力値、かんたんの照準・耐久・装填などの補助は維持する。進化した武器は専用の戦闘処理と立体モデルへ切り替わる。狙撃銃の1発装填と、ASTRAの最大24発・EXPLOSIONの24発全消費も維持する。

## カードの選び方

レベルアップ・ウェーブ報酬に6武器と「共通強化」のタブを用意。初期表示は使用中の武器で、タブを切り替えて育てたい武器の次のカードを探せる。武器タブは対象武器の進化候補を優先し、他武器・共通強化の候補も補う。1回の報酬で取得するカードは1枚。タブの閲覧だけでは報酬や回復を追加取得せず、カードを選ぶまで進行しない。表示には現在の段階、次の威力倍率・装弾数、形態図を添える。かんたんでは武器名と説明を読みやすい表現にする。

## 武器ごとの役割

倍率は同じ武器の未強化状態に対する基本威力。共通カード、コア命中、距離、OVERDRIVE、ボスの露出補正などは別に適用される。

| 武器 | コア／ルート段階／最終段階の基本強化 | ルートと完成時の挙動 |
|---|---|---|
| 散弾砲 | 威力×1.65／×2.4／×3.6。14／18／24発、散弾10／12／14粒。最終の射撃間隔0.38秒、装填0.9秒。 | **渦流型 → サイクロン**：広い散弾と半径7mの前方圧力波、基礎8m相当の押し戻し。**破砕型 → カルデラ**：散弾を集束し、命中地点に半径5mの破砕爆発。 |
| レールガン | 威力×1.65／×2.4／×3.5。8／10／14発。最終の射撃間隔0.48秒、装填1秒。 | **屈折型 → クロマ**：直線貫通に加え、最大4体へ90%威力の屈折連鎖。連鎖1回の距離24m。**攻城型 → オベリスク**：直線貫通に追加倍率×1.8。建築物は貫通しない。 |

散弾砲は進化後も近距離向け。直接散弾の距離補正は8m以内×1.25、14m以内×0.45、それ以上×0.06。渦流の圧力波の中心は銃から前方最大6mに制限し、遠方への散弾1粒で大威力の衝撃波を転送できない。破砕爆発も最初の命中距離による減衰を引き継ぐ。爆風・屈折・反響は遮蔽物を判定し、壁の向こうの敵へ無条件に届かない。

### EXPLOSIONの強化

既存のEXPLOSIONに対し、`基本威力倍率 × NOVA追加倍率 × EXPLOSION追加倍率` を掛ける。コア取得時は×1.43、星震型の最終進化は×4.29、循環型の最終進化は×2.6。照準方向の直撃と衝撃波の威力に反映する。発動には従来どおり24発すべてが必要で、チャージ短縮が弾数消費を割り引くことはない。遮蔽物・距離・ボスの既存補正も残る。

## 立体モデルと演出

5武器に各5形態、合計25形態の進化用立体キットを用意。基本モデルの特徴と実際の銃口を保ちながら、段階・ルートごとにシルエットを変更する。

- 散弾砲は銅色の圧力槽を増設。渦流は開放タービン、破砕は強化チャンバーと機械的な銃口の顎へ変形する。レールは分割加速器を延長し、屈折用の結晶開口部か攻城用の重い補強構造へ分岐する。
- ASTRAは星震用の投射花弁か循環用の側面反応槽を展開。狙撃銃は開いたスコープと長い銃身を保ち、反響導体か精密加速器を追加する。ミサイルは三連発射筒を保ち、群体用の側面翼か追撃用の装甲を増設する。
- 射撃・命中には武器別の光線、圧力リング、屈折片、位相波を使用。静的な部品を材質別に統合し、戦場エフェクトは固定プールで再利用する。停止中は寿命を止め、再スタートで残留を消去。低画質・視覚効果の軽減設定にも対応する。

## 共通カードとの組み合わせ

専用進化を選び終えても共通強化を選べる。進化した散弾・レール・狙撃には空中制圧、地走電流、コア狙撃、OVERDRIVEなどの射撃補正が適用される。

- 散弾の押し戻しは既存の近接制圧カードで増幅し、遮蔽物に押し付けた場合の追加ダメージにもつながる。
- レールの屈折／攻城と既存の分裂カードを併用できる。進化による直撃・連鎖後、撃破地点から追加の分裂先を探す。共通電弧も追加対象と射線を確認する。
- 精密型狙撃は上部コア命中への専用倍率と共通のコア狙撃を重ねられる。反響型は直接撃破から集団へ連鎖し、役割が異なる。
- 慣性蓄電はOVERDRIVEへの到達・継続を助け、循環型ASTRAの弾補充と組み合わせられる。自動装填は従来の通常3武器向けで、ASTRAの24発を無条件に補充する効果にはしない。

## 検証状況と制限

再検証は `npm run test:arsenal`。専用のビルド定義・カード順序、戦闘処理、立体モデルと固定プール、実際の報酬選択・PC／タッチ・武器切替・難易度・停止／再スタートを対象とする。

確認済み：新規のビルド定義・カード制約テストと、重火器／特殊武器のモデル・エフェクト単独テストが通過。重火器の進化キットは最大19描画オブジェクト／7,308三角形で、銃口位置、FPS用のモデル範囲、プール再利用、停止・寿命・リセット、有限な変換行列を確認した。

ゲーム本体の統合テストも通過。10ルートの実際の報酬取得と排他制約、専用攻撃、共通カードとの相乗効果、23発NOVAと24発EXPLOSIONの両ASTRAルートでの大小関係、メニュー復帰時の武器・エフェクト消去を確認した。実際の武器配置を用いた座標投影では、全10最終形態をPC 16:9・スマホ横・縦画面で確認し、画面中央の水平線を覆うモデルやモデル全体の画面外への脱落はなかった。これは数値的な投影確認で、描画目視の証拠ではない。

最終確認で `npm run build`、`test:arsenal`（5サブスイート）、`test:weapon-parity`、`test:phase`、`test:phantom-lance`、`test:explosion`（音声を含む）、`test:seeker`、`test:training`、`test:pulse`（演出を含む）、`test:world`（地形を含む）、`test:enemy-visuals` がすべて終了コード0。未強化武器の比較もヘッドレスで通過した。

現在の管理環境には必要な `cua_repl` がなく、ブラウザ目視QAは実施できていない。実際のiPhone Safari、端末上の視認性・フレームレート・発熱も未検証。自己採点を品質保証として提示しない。
