# 50点からの戦闘操作見直し

ユーザー指摘: 「巨人と戦っている感が薄い」「戦いにくすぎる」「敵に吸い付くようにするべき」。前版は公開90。自己採点による90点判定を完了条件にしない。

## 変更

- 右クリック長押しで巨人の広めの範囲から標的を選択。建物の遮蔽と近い通常アンカーを優先し、壁越しには選ばない。通常の建物ワイヤー操作は維持する。
- 破壊前は肩装甲、破壊後はうなじを接近先にする。正面からうなじへ直進せず、巨人の側面から回り込む案内経路を使う。顎は頭部が胴体前方へ出るため、頭の背後に到達するよう接近先を補正する。
- 金属ワイヤーの端点は巨人の肩・うなじに接続し、移動の案内点と分ける。回り込み途中に近接解除せず、攻撃位置に入ると自動解除。手動の右クリック解除も維持する。
- 巨人への接近中は速度を抑え、低空からの打ち上げを小さくする。通常の都市飛行は同じ速度。弱点へカメラを緩やかに向け、マウス入力中は手動視点を優先する。背後の近距離まで到達した最初の一回は0.55秒の隙を作り、急旋回で接近を無効化しない。
- 近距離クリックで0.2秒の踏み込み斬撃。命中時に距離、背後、遮蔽を再判定する。移動と同時に即ダメージを入れない。接近からつないだ斬撃は68、近距離で繰り返す斬撃は34。通常/顎の市街地敵は接近斬撃で一体を倒せる。鎧は各肩3回で破壊、雷槍でも破壊できる。
- 斬撃中、実際の刃の移動区間と動く弱点の位置を追跡する。超大型などアニメーションでうなじが動いても、剣の軌道が触れた斬撃を空振り扱いにしない。結果は装甲/うなじ別の表示にする。
- 命中時は火花、斬撃アーク、照準点へ集まる集中線、0.075秒のヒットストップ、短い画面揺れ、部位ごとの音を出す。装甲は金色、うなじは赤白で分ける。
- 討伐時は巨人を倒れ込ませて蒸気を出し、3.35秒後に結果画面へ移る。巨人の表示が消えてからリザルトを出す。
- 討伐後はワイヤー・カメラの対象を解放し、離脱速度を付ける。変身中には吸着しない。再出撃時は状態を消去する。
- 肩装甲の近距離斬撃では肩の中心も判定し、胴体のレイに吸われる空振りを減らす。雷槍も選択中の肩を狙いやすくする。
- 巨人が家に引っかかって止まる問題へ、同じ地形コライダーを使う地上経路探索を追加。角を横切らず、路地や建物の周囲を旋回して接近する。

## 検証

`npm run test:titan`、`node tests/titan-combat-assist.cjs dist/ODM_TITAN_RAID.html`、`node tests/titan-roster.cjs dist/ODM_TITAN_RAID.html`。

新規の通し検証では、実際のGLBとゲームループ・PC入力を使い、地上55m前方から右クリック長押し→背後へ接近→クリック→遅延した命中を通常/顎/超大型で確認。命中部位・ヒット演出UI・集中線、鎧の3回斬撃、全12体の討伐、蒸気中の待機、巨人消失後のリザルト表示、対象解除、壁の遮蔽、建物ワイヤー、巨人化中の操作遮断を確認する。

経路探索は壁、折れた中庭、屋上の目標、ステージ変更を検証。実際の市街地の家の列を巨人が通り抜けず迂回して追跡することも確認する。

検証は実際のThree.jsのジオメトリと計算を使うが、WebGL描画は代替レンダラー。ブラウザでの見え方、FPS、操作の体感まで合格したとは扱わない。

## うなじ誘導の再調整

- 巨人の自動ロック距離を160mから110mに縮め、カメラ前方から外れた巨人を拾いにくくする。
- 右クリック長押しの自動接近は、うなじの後側方およそ7mで停止してワイヤーを解除する。超大型巨人でも補助が切れないよう、接近維持の距離は胴体の根元ではなく誘導対象のうなじから測る。
- 停止後はカメラ補助を切り、後ろへ回る移動と照準をプレイヤーへ返す。自動カメラは接近中だけ、胴体中央へゆっくり向ける。
- うなじ斬撃は8m以内、背後比率0.78以上、照準一致0.75以上を開始条件にする。遠距離クリック、照準を外した攻撃、正面からの攻撃では踏み込み斬撃を開始しない。
- 動くうなじを追う刃の軌跡判定は維持し、命中距離だけ2.5mまでに絞る。火花、集中線、ヒットストップ、命中表示、討伐時の崩れ・蒸気演出は既存のまま残す。
- 接近経路の広角な自動吸着を抑えつつ、鎧の装甲斬撃、雷槍、通常の建物アンカーは維持する。

再検証: `npm run test:titan`。通常/顎/超大型のステージ停止、手動照準、9m攻撃拒否、狙い外し拒否、命中演出と撃破、装甲3回斬撃、レイド継続、壁越し取得拒否を通す。
