# OVERDRIVE v7.0 — Ω / RIFT RAID 開発レポート

2026-11-13。対象は難易度Ω。通常・かんたん・Xの進行は継承。

## 今回の改革

| 項目 | v6.2 | v7.0 |
|---|---|---|
| 主目的 | 6ウェーブの敵全滅 | 4種類の任務から5コアを奪い、最後に中枢ボスを撃破 |
| 世界の寿命 | 戦闘20秒 | 最大20秒。達成後は任意で即時脱出できる |
| 武器 | 毎回選択画面の3択 | 開始時だけ3択、その後は自動交換＋各世界1回の引き直し |
| 敵 | 有限の出現キュー | 任務中は上限付きの増援。全滅待ち不要 |
| レベルアップ | 選択画面で停止 | 耐久・装填を自動強化、プレイ継続 |
| 失敗 | 耐久0 | 耐久0、または任務4回失敗 |

任務達成後に留まると経験値や回復を拾える一方、敵の増援は続く。E／次へボタンで即座に次の世界へ移れるため、残り時間を使う価値を判断する構造にした。5コアを集めた後の脱出では中枢ボスが出現する。

## 実装した任務

- BREACH：46HPの封鎖装置3基を射撃破壊。全武器の通常の射撃経路で命中し、破壊装置は敵キルや経験値を重複生成しない。
- RELAY：2か所を順番に制圧。半径2.2m・床から高さ3m以内で1.25秒維持。離れると占拠途中の進捗が緩やかに減る。
- ROUTE：3個の光るゲートを順番に通過。判定半径1.9m。別の順番では進捗しない。
- HUNT：金色の立体マーカーを付けた敵2体を排除。他の敵を倒しても任務進捗は増えない。

目標は移動可能な床へ置き、直線距離に加えて実際の経路長を調べる。通常の1区間を24m以内に制限。直近と同じ任務は連続抽選しない。

成功：コア+1、1000点、耐久12回復、4秒OVERDRIVE。レベルアップ：最大耐久+3、耐久5回復、装填時間を5%ずつ短縮（8段階上限）。武器引き直しは残り時間・無敵時間・HPを増やさない。

通常増援は最大6体。ボス戦はボス込み最大4体。最初のボス出現時だけ通常敵を整理し、その後の再構築では同じボスのHPを引き継ぐ。ボス戦では任務失敗数を加算しない。ボス撃破だけが最終勝利条件となる。

## モデリングとHUD

新規の破壊炉・制圧端末・通過ゲート・追跡マーカーを追加。装甲、セラミック、発光コアで見分ける。静的部品は材質ごとに結合し、フレーム内にジオメトリやマテリアルを生成しない。

3目標を表示した静的計測は、破壊炉30描画／5784三角形、制圧端末27描画／4164三角形、ゲート18描画／2856三角形、標的12描画／2514三角形。これは追加モデル分であり、端末のFPS計測値ではない。

HUDは任務、進捗、残り秒数、5コア、4失敗を表示。目標の画面マーカーと距離表示を追加。PCではQで武器引き直し、達成後Eで早期脱出。スマホは同じ操作ボタンが達成後に「次の世界へ」へ変わる。既存の射撃・移動ボタンを継承。

## 実施した検証

- `npm run build`：単体HTMLと公開用静的ファイルを生成。
- `npm run test:omega`：125戦闘ビルドの既存検証、新しい純粋な進行状態テスト、実ゲームコードでの4任務・20秒再構築・自動武器交換・引き直し・早期脱出・経験値・ボス・敗北・再出撃・難易度分離を検証。
- `npm run test:world`：既存ステージ、接続性、ジャンプ台、加速盤、浮遊、リフト、リレー、アンカーの回帰検証。
- `npm run test:weapon-parity`：通常・かんたんの武器役割と補助の互換性。
- `npm run test:x`：Xの進行、時間操作、専用ボス、勝敗と再出撃。
- 既存PlaywrightのΩシナリオは新仕様へ更新し、構文確認。今回の実ブラウザ実行は未実施。

実ゲームコードの検証はNode.jsと実Three.jsの数学・モデルを使い、DOMとレンダラーを置き換えたもの。描画された画面の目視や人間のエイム能力を測ったものではない。

## 発見して修正した不具合

1. 散弾のノックバックで封鎖装置の当たり判定だけが台座から3m離れる問題。固定目標を移動対象から除外し、実射撃で再確認。
2. WARDEN自身の召喚が通常増援と別の上限を使い、ボス込み5体になる問題。Ωの共通上限4体に統一し、自然なボス行動を進めて再確認。
3. 次の制圧端末・ゲートを有効化しても初期フラグにより暗いままになる問題。現在の有効フラグを参照するよう修正。
4. 再構築時に回復オーブの古い座標を参照して移動されない問題。現在の実際の座標から新しい足場へ配置。
5. タイトルへ戻ったときに任務・固定目標・敵弾が残る問題。Ω終了経路で除去。
