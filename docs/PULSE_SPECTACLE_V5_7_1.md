# OVERDRIVE v5.7.1 — TEMPEST / HELIX 演出強化

## 実装

連鎖型の直接撃破で、撃破地点へ天雷が落ちる。細い先行光から約0.065秒後に、白い芯・紫の外光・枝雷が走り、床へ衝撃リングが広がる。連鎖の電弧も落雷から順に広がるよう表示する。雷撃のダメージ処理は従来と同時で、視覚演出のみを短く遅延する。最終形態は通常進化より雷を太く高くする。

落雷は最短0.22秒間隔。連鎖先それぞれに巨大落雷を落とす方式ではなく、直接撃破地点の落雷を連鎖の起点とする。ウェーブごとの地面高さへ接地する。画面全体の白フラッシュやカメラ揺れは追加していない。

貫通型では5段／最終7段の加速器のランプが、命中充填に応じて両側から順に発光。充填完了時は白熱色へ変わり、前方レールと回転機構が展開する。発射時は二重らせんの橙色航跡・白熱した芯・銃口リング・5段の加速波・二重の着弾衝撃リングを表示する。強い発光と機構の動きは銃と弾道の周囲に集めた。

ダメージ、装填数、発射間隔、連鎖の対象判定、充填に必要な命中数はv5.7と同じ。PC／スマホ、両難易度に適用する。

## 負荷と状態管理

専用演出は固定168枠・4つのInstancedMeshに集約。モバイル／LOWでは枝雷・らせん・リング数を減らす。OSの動きを減らす設定では主雷と砲撃を短縮し、らせんや放射線を抑える。ランプも各モデル1つのInstancedMeshへ集約する。

遅延演出は一時停止時に停止し、再出撃・ホーム・世界再構築時に消去する。視覚演出の待ち行列には上限を設け、撃破が集中してもダメージ処理を遅延させない。
