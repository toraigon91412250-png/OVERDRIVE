# OVERDRIVE v8.1 — Σ / FRACTURE RAID 調整

2026-11-13。Ωを残したまま新難易度Σを追加。初回版はΩと同じ敵編成を使っていたため、射撃型に偏る戦場で遠距離弾が重なり、Σの「近接戦＋捕獲返撃」という遊びに合わなかった。Σだけの敵編成とボス弾数に分離し、Ωの戦闘は維持した。

## 近接中心の敵編成

- Σの初期6体は近接型・突進型5体と射撃型1体。浮遊射撃型は出現しない。
- その後の補充は近接型・突進型のみ。Σで同時に生きている遠距離型は最大1体。
- 指名標的の補充も近接型に限定。
- WARDENの扇状射撃はΩの7発からΣでは3発に変更。Ωの7発は維持。
- 世界再構築ごとの武器交換と任務進行は前回の仕様を維持。

## 戦闘の改革

### キネティック・アーム

- PCはF、スマホは専用ボタン。空の状態で使うと0.55秒の捕獲姿勢へ。再使用間隔0.9秒。
- 正面約81度以内かつ4.2m以内に来る敵弾を捕獲。画面の前方ベクトルと、弾が通った線分を調べる。
- ダッシュ中は2.2m以内を通る弾を方向に関係なく捕獲できる。
- 最大6発。満杯になると追加の弾を吸収しない。捕獲そのものではプレイヤーに無敵を追加しない。
- 1発でも蓄えた状態でF／返撃ボタンを押すと、全弾を返す。捕獲の再使用待ちの途中でも返撃可能。
- 1発42ダメージ。照準から約26度以内・65m以内・遮蔽物に隠れていない最大3体へ配分する。通常の銃の弾数は消費しない。
- 6発返撃は着弾点に半径6mの追加衝撃波（最大60、距離減衰、最大3体、ボス補正あり）と、半径7mの防壁破壊を起こす。
- 照準付近に敵がいなければ、狙った壁へ蓄積弾を撃つ。捕獲弾は世界再構築で消える。

左手の立体ガントレットは可動クロー、発光機構、6個の蓄積セルを持つ。捕獲は弾の位置から手へ曲がる光束、返撃は集束光束とリングを表示。最大27描画・1780三角形、エフェクト30枠の上限。フレーム内の新規形状・素材生成を避けた。これは追加モデル分の測定で、実機FPSの測定ではない。

### 壁を壊して戦場へ介入

Σのシアンの継ぎ目・琥珀色の上端を持つ防壁は72HP。本編6武器、進化武器、生成武器5コア、返撃、NOVA／EXPLOSIONの実際の命中・着弾からダメージを受ける。照準補助・敵AI・ロックオンの見通し確認だけでは傷つかない。

破壊時に見た目、衝突、通路の障害を同時に除去し、50点を得る。床とジャンプ台は破壊しない。敵も開いた通路を使える。再構築後は新しい壁として復元する。

被弾で亀裂が増え、破壊で10個の破片と拡大リングを出す。破片48・リング4の固定プール。壁IDを維持し、描画インスタンスと当たり判定の対応を崩さない。

## 継承した進行

30秒の4任務、3コアから中枢ボス、任務6回失敗か耐久0で敗北。開始時の武器選択、世界ごとの武器自動交換、Qで1回の引き直し、達成後Eで早期脱出、敵の補充、停止しないレベルアップはΩと共通。新戦闘を使わない前回Ωもそのまま選べる。

Ωの最高記録キーは `overdrive-omega-raid-v1` を継承し、Σは `overdrive-fracture-v1` を使用する。片方の記録を上書きしない。

## 実施した検証

- `npm run build`：公開用静的ファイル・単体HTML生成。
- `npm run test:fracture`：Σ編成500シード、実戦時の遠距離敵上限、Ωとのボス弾数差、純粋な捕獲状態、実Threeモデル、壁レイ判定・経路開通、返撃・武器別壁破壊を確認。
- `npm run test:omega`：従来Ωの4任務・20秒再構築・5コア・ボス・敗北と生成武器の回帰。
- `npm run test:world`、`npm run test:weapon-parity`、`npm run test:seeker`、`npm run test:arsenal`、`npm run test:x`：従来の地形、通常・かんたんの武器、シーカー、進化武器、Xの回帰。

実際に通る線分を使った前方／背面／ダッシュ捕獲、未使用時の通常被弾、6発上限、時間と弾数を巻き戻さない返撃、遮蔽物越しに返撃が当たらないことを検証。シーカーと生成武器の遅延着弾もフレームを進めて確認した。旧Ωでは捕獲・壁破壊を有効にしないことを検証した。

検証中、生成武器の着弾点が浮動小数点誤差で壁面の手前になるケースを見つけ、最終衝突面の確認に0.01mの許容を設けた。飛行中の余分な壁レイ検査を避け、実際の着弾時だけ通知する。

## 検証の限界と公開状況

実ゲームコード・実Threeの数学と形状を使用するが、ヘッドレス検証ではDOMとレンダラーを置き換えている。今回の環境にSites指定の `cua_repl.js` がなく、ブラウザ目視とiPhone Safari実機のFPS・発熱・操作感は未確認。環境指示に従って別経路のブラウザ操作は行っていない。

Sitesの認証を取り直して、修正後のコミットを公開ブランチへ送信し、同じコミットから作った配布物で公開版を更新した。公開バージョン番号とURLは公開後に追記する。ブラウザ目視とiPhone実機のFPS・発熱・操作感は引き続き未確認。
