# OVERDRIVE v5.7 — パルス進化の実験

## 実装

通常のレベルアップ／ウェーブ報酬で、パルス専用カードを追加した。毎回、現在取得できる進化カードが必ず候補に入り、残りは既存の強化から選ぶ。

1. コア増幅を選択。
2. 連鎖型か貫通型を選択。この周回中は変更できない。
3. 選んだルートの最終進化を選択。

各段階の取得時にパルスを満タンまで装填する。現在装備中の武器は自動で切り替えない。進化はその周回のみ。カード画面に成長段階と次の進化を表示し、武器HUDには形態・貫通砲の充填状況を表示する。

PCとスマホ、両難易度に適用。かんたんの体力・敵弱体化・照準補助・パルス16/7倍補助・0.55倍リロードは維持。かんたんの武器HUDと進化カード見出しには平易な名前を使う。練習から本番への移行時には進化状態も初期化する。

## 数値

補助・弱点・移動系カード等を掛ける前の通常難易度の値。ユーザーの指定により、完成したパルスを意図的に突出させた実験値であり、武器全体の均等なバランスは目標としていない。

|状態|得意距離での胴体威力|装填|発射間隔|装填時間|最大威力の距離|
|---|---:|---:|---:|---:|---|
|未強化|7|50|0.105秒|1.25秒|9–15m|
|コア増幅|13.3（×1.9）|64|0.085秒|1.05秒|7.5–18m|
|ルート進化|19.6（×2.8）|80|0.077秒|0.95秒|6.5–21m|
|最終形態|30.1（×4.3）|100|0.064秒|0.80秒|5–25m|

近距離には低威力帯と2mの立ち上がりがあり、得意距離の外では距離減衰する。減衰がゼロになる距離は27 / 34 / 41 / 50m。RANGE TUNERは従来どおり得意距離を拡張する。OVERDRIVE、空中／スライド、コア命中、追撃回路と組み合わせられる。

### 連鎖型 → TEMPEST

- ルート進化：直接命中から近くの1体へ65%威力の電弧。直接撃破なら最大3体へ100%。1リンク9m。
- 最終形態：直接命中から最大3体へ85%。直接撃破なら最大5体へ140%。1リンク12m。
- 対象を一度ずつ訪れる鎖。各区間で遮蔽物を確認し、壁を通さない。二次雷撃から再帰的な雷撃は起こさない。
- 雷撃にも対象ごとのボス露出係数、移動系カード、追撃回路を反映。撃破は通常のスコア・XP・回復・自動装填処理を使う。

### 貫通型 → HELIX

- ルート進化：通常弾を6回命中させると次弾が5倍貫通砲（基本98）。
- 最終形態：4回命中で次弾が8倍大型貫通砲（基本240.8）。
- 貫通砲の消費は1発。射線上の敵を全て貫き、遮蔽物で止まる。砲撃自体で次の砲撃を充填しない。
- 貫通砲は射程内で最大威力を維持し、通常弾より広い命中幅を持つ。通常弾の空振りでは充填しない。
- 充填は武器切替・装填・一時停止・ウェーブ再構築をまたいで保持。次の周回では初期化。

## モデリング・演出

5つの専用進化モデルを手続き生成。コア増幅モデルを共通に、両ルートの第2・最終形態を用意した。

- 銃身、面取りした装甲、照準器、グリップ、分割マガジン、排莢部、コア保護枠、ネジ、導電レール、識別プレートをモデル化。
- TEMPESTは白い装甲、シアンと紫の3連セル、分岐導電機構、可動する前方機構。
- HELIXは銅色のフレーム、7段の加速器、橙色の内部導線、命中充填に応じて展開する機構。
- 射程を示すコア色は継続。砲撃充填と射撃に合わせてコア／導電部が発光。
- 段階取得時の取り出し・展開、排莢、反動、実際のマガジンとボルトの装填動作。
- 弾道はモデルの銃口から開始。電弧は折れ線、砲撃は白熱した芯と橙色の航跡、加速波、着弾リングで表現。
- 新エフェクトは72枠の固定プール・3つのInstancedMesh。モバイル／LOWでは雷撃の分割数と加速波を抑制。
- 進化モデル単体は最大26メッシュ／4,730三角形。静的部品を素材ごとに結合し、画面中央の照準線を空けた。

## 検証と修正

`npm run test:pulse`：実際のゲーム本体をThree.jsの実幾何・行列と非描画DOM環境で実行。カードの3段階取得／分岐排他／二重クリック、実ダメージ、雷撃の対象数と重複排除、遮蔽、砲撃の充填・貫通、ボス露出係数、空撃ち開始の装填動作、スマホ長押し、武器切替、停止／再出撃、報酬待ちと再構築を検証した。モデルは16:9、844:390、390:844の投影で視線と銃口の配置、有限な頂点、ポリゴン数を検査。

既存のphase、world、seeker、training、phantom-lance、explosion／audio、weapon-parityの各テストも実施。ビルドと差分チェックを実施。

古いv5.4比較データは、変更前のv5.6でも散弾3ケースに差が出る状態だった。変更前コミット `552317131901ca9b8c55b207ae171784352d1513` を一時的に実行して、直前版の比較データ `normal-weapons-v5.6.json` を取得した。今回意図的に変更したカード候補は専用テストに分離し、既存の未強化武器・他武器の戦闘値は直前版と完全一致することを確認した。旧v5.4データは保存。

作成中に最終モデルの見た目の差が小さかったため、後部装甲と上部コアまで再設計。カード再クリックの排他チェックと、実際の装填時間に追従するアニメーションも追加した。

## 検証範囲・制限

確認環境はLinux / Node.js 24 / Three.js 0.170。WebGLRendererとDOMをテスト用の代替実装に置き換えた自動検証であり、人間の実プレイや実ブラウザの描画性能を保証するものではない。

管理環境にSites指定の `cua_repl.js` とブラウザ操作ツールがなく、Sitesの手順に従ってプレビューサーバーや別ブラウザを起動していない。別途、実際のモデル頂点をカメラへ投影したオフラインの幾何画像で、形態の差を確認した。これはゲーム画面のスクリーンショットではない。今回のiPhone Safari実機、タッチの押し心地、発熱、実フレームレートは未確認。

自己評価として、進化の明確さ・モデルの差・強さの伸びは実装／数値で裏付けられた。面白さと実機での見栄えの評価は、ユーザーによる実プレイで継続する。他武器への進化カードは次段階。
