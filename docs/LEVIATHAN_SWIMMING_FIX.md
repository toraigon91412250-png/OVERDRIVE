# LEVIATHAN 水中移動の修正（2026-11-17）

対象: `src/game.js`。HP50%で水中戦へ移行した後、水中で横移動できない場合がある問題を修正。

原因: 地上の甲板（高さ0.5m）を使う移動判定を、水深約3mに潜ったプレイヤーにも適用していた。さらに潜航演出中に `input.x/y` と `input.keys` を毎フレーム初期化していたため、iPhoneでスティックを押し続けても演出終了後に再操作するまで移動入力が戻らなかった。

修正: LEVIATHANの水中遊泳中だけ甲板・柱の地上用横移動ブロックを適用せず、既存のアリーナ境界と水深・水面制限を維持。演出中は移動計算で入力を無効化し、入力データ自体は消去しない。射撃は演出中停止。

確認: `node tests/leviathan-swim-regression.cjs`（外部パッケージ不要）および依存モジュール導入後の `npm run test:leviathan` と `node tests/leviathan-integration.cjs`。後者に水中WASD移動とスティック長押しの再発防止テストを追加。
